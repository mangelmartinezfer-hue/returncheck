Alta en directorios MCP

Estos son los sitios donde los agentes y desarrolladores descubren herramientas MCP. Copia y pega el texto de cada bloque. El texto va en inglés porque son directorios internacionales — es lo correcto aquí.

Antes de empezar — dato clave: ya estamos en el MCP Registry oficial, y varios directorios (Glama, PulseMCP) lo rastrean solos, así que puede que aparezcamos ahí en unos días sin hacer nada. Concentra el esfuerzo en mcp.so, Smithery y el PR a awesome-mcp-servers. Si en Glama/PulseMCP ya te sale ReturnCheck al buscarlo, ¡mejor, tachas y a otra cosa!

Datos para copiar (valen para todos)

Nombre
ReturnCheck
Una línea (tagline)
Verified return-policy answers for AI shopping agents — never guesses.
Descripción
Ask "can this specific product actually be returned?" and get a verified verdict (YES / YES_WITH_CONDITIONS / NO / UNKNOWN) with the exact policy clause, source URL, return window and confidence. It never invents: returns UNKNOWN if it can't verify a clause. MCP tool check_return. $0.02 per verified answer, UNKNOWN is free, keyless free trial available.

Los directorios, uno a uno

1

mcp.so

El directorio más grande de servidores MCP. Busca el botón “Submit” (arriba a la derecha) y rellena con los datos de arriba. Pega el MCP endpoint donde pida la URL del servidor.
https://mcp.so/submit
2

Glama

Primero busca “ReturnCheck” en su buscador: si ya aparece (lo cogió del registry), listo. Si no, busca la opción “Add server”.
https://glama.ai/mcp/servers
3

PulseMCP

Igual que Glama: busca “ReturnCheck” primero. Si no está, busca “Submit” en el pie o el menú.
https://www.pulsemcp.com
4

Smithery

Normalmente conecta tu repo de GitHub. Requiere que el repo sea público (ver paso 6). Inicia sesión con GitHub y usa “Add server” apuntando al repo returncheck.
https://smithery.ai
5

awesome-mcp-servers (GitHub)

Es una lista muy visitada. Se añade con un Pull Request: pulsa el lápiz para editar el README, añade una línea con el nombre y enlace, y crea el PR. Si te lía, dímelo y te escribo yo la línea exacta y el paso a paso.
https://github.com/punkpeye/awesome-mcp-servers
Línea para el PR (ejemplo)
- [ReturnCheck](https://returncheck.m-angelmartinez-fer.workers.dev) - Verified return-policy answers for AI shopping agents; MCP tool check_return, never guesses.
6

Hacer público el repo de GitHub

Para que buscadores y agentes lo indexen (y para Smithery). En tu repo: Settings → General → Danger Zone → Change visibility → Make public. El README ya está optimizado.
Consejo: si un directorio te pide algo raro o no encuentras el botón, hazme una captura y te guío. Cuando termines una tanda, avísame y comprobamos que la API responde bien a quien la descubra.
