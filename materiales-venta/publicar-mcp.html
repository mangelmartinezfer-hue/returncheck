ReturnCheck · guía de publicación

Publicar en el MCP Registry

4 pasos que corres tú en tu ordenador (necesitan tu login de GitHub, por eso no puedo hacerlo yo). Al terminar, los agentes que hablan MCP podrán descubrir check_return. Todo desde la carpeta returncheck, en PowerShell (Windows).

Antes de empezar: abre PowerShell dentro de tu carpeta del proyecto. Truco fácil: abre la carpeta returncheck en el Explorador de archivos, y en la barra de dirección escribe powershell y pulsa Enter. Se abre ya situado en la carpeta.
PASO 1 · instalar la herramienta mcp-publisher

Descargar el publicador

Pega esto tal cual y pulsa Enter. Descarga un programita al que llamaremos después.

$arch = if ([System.Runtime.InteropServices.RuntimeInformation]::ProcessArchitecture -eq "Arm64") { "arm64" } else { "amd64" }
Invoke-WebRequest -Uri "https://github.com/modelcontextprotocol/registry/releases/latest/download/mcp-publisher_windows_$arch.tar.gz" -OutFile "mcp-publisher.tar.gz"
tar xf mcp-publisher.tar.gz mcp-publisher.exe
Remove-Item mcp-publisher.tar.gz
PASO 2 · identificarte con GitHub

Login (te da un código)

Esto abre una identificación por código: te dará algo tipo ABCD-1234 y un enlace. Ve al enlace, mete el código, autoriza. Vuelve a PowerShell cuando diga "Successfully authenticated".

.\mcp-publisher login github
PASO 3 · publicar la ficha

Enviar server.json al registro

Ya está el server.json en la carpeta (lo preparé yo). Este comando lo publica.

.\mcp-publisher publish

Debe responder algo como ✓ Successfully published · io.github.mangelmartinezfer-hue/returncheck 1.0.0.

PASO 4 · comprobar que estás dentro

Verificar

Pega esto; debe salir tu servidor en el resultado.

curl "https://registry.modelcontextprotocol.io/v0.1/servers?search=returncheck"

Si ves "name":"io.github.mangelmartinezfer-hue/returncheck" en la respuesta, ya estás publicado. Pásame lo que salga y lo confirmo contigo.

Si algo se atasca: no pasa nada, no rompes nada. Cópiame el error tal cual y te digo el arreglo. Publicar es reversible y actualizable (se puede volver a publicar subiendo la versión). No es urgente hacerlo hoy si estás cansado.
Qué NO hace falta: aquí NO se sube nada a npm ni se toca cripto — es un servidor remoto, así que el registro solo guarda la ficha que apunta a tu /mcp. El endpoint ya está vivo y funcionando.
